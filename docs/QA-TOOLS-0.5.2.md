# 0.5.2 手动测试工具

仅在农场名以 `AnniversaryQA` 开头的测试存档可用。先离开节日，再按 F8。工具只在玩家点击或输入命令后执行，开发侧没有自动触发死亡或修改存档。

## 面前生成巨大作物

在农场站好、面朝一块完整的 3×3 空地，按 F8 →「面前生成巨大作物」。生成一株真正的原版巨大花椰菜，可收获、保存，也可用于测试巨大作物移动工具。

创建由主机执行，客机也能发起。前方存在人物、建筑、物品、其他巨大作物、已种植作物、水面、树或灌木时拒绝生成，不清空或覆盖原有东西。同一网络请求只创建一次。

控制台等价命令：`anniversary_qa crop`。

## 两种救援

F8 →「测试昏倒 / 战败（医疗卡）」会显示随身背包里的两种卡片数量。不会自动给卡、强行扣卡或调用保护补丁；你可以分别测试带卡与不带卡的结果。

- **触发昏倒（月亮卡）**：在农场等普通户外区域操作，金币至少 10。将体力设为 -16，由原版检测耗尽、播放昏倒、回家并结算费用。有月亮卡时应消耗一张并免除本次费用；没有卡则按原版收费。安全区域或零费用不会验证到月亮卡，因此工具会提示先换地点或准备金币。控制台命令：`anniversary_qa passout`。
- **生命归零战败（火星卡）**：将当前玩家生命设为 0，由原版死亡画面和救援事件继续。有火星卡时应消耗一张并保护金币和物品；没带卡时按原版结算。控制台命令：`anniversary_qa defeat`。

两个救援按钮只影响操作者，不会让另一位玩家同时倒下。普通昏倒的过夜/联机等待和战败救援的地点、时间都沿用原版；来信在次日检查。凌晨 2 点后、剧情/节日中或已经处于救援状态时，不重复触发。

本次只做了代码、原版触发条件核对和构建/包检查，未运行实机 QA。更新需关闭全部游戏窗口，再通过 `Launch-AnniversaryQA.cmd` 装入 0.5.2。
