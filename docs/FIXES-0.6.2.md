# 0.6.2 切蛋糕与家中小外

本版为本地手动 QA 包，未发布 GitHub Release。开发侧核对原版绘制、照明 API，完成编译和包检查，没有启动游戏或执行自动游玩。

## 切蛋糕

- 每次完成挑战均由主机发奖：两刀间距不超过 0.15，每人 2 束，否则每人 1 束。结束后可再次找格斯或蛋糕桌邀请搭档。
- 第一人落刀后菜单保持打开，固定落点并等待另一人。
- 第二人落刀后，两边都保留同一块结果板 8 秒：红线标第一刀、蓝线标第二刀，分别写明玩家名字，同时显示间距与奖励。两条线错开上下端，即使落点完全一致也不会互相盖住。
- 结果期间再点击、空格或手柄 A 不会提交或提前抹掉结果。Esc、B 或右上角关闭可提前收起本地界面，奖励保留；8 秒结束后活动解除占用，可重新邀请。
- 完成之前取消、超时或断线仍取消本次挑战，不发奖；同一局的重复输入不会重复发奖。

请手动连玩两次，互换先后手，检查双方均有两条结果线、结果不会瞬间消失、两次都收到奖励。再试等候搭档时取消，并重新邀请。

## 回窝作息与墙边

- 21:00 开始结束白天闲逛，沿四向可走路径回到小窝，再钻进窝里睡下。晚上进入房间时，小外已在窝里睡觉。
- 白天保留原来的休息比例与右键后移动；晚上睡觉优先，右键不会让它再次离窝。次日有可走位置时恢复白天活动。
- 寻路检查地图、家具和人物占用；道路暂时被人挡住时等待，必要时沿刚走过的小段退回重选。完全堵住时不会穿墙或传送，请给小窝留出通道。
- 排除墙壁/地图空白旁的一圈、门口传送格及脚下有 Front/AlwaysFront 图块的位置。找不到安全出生位置时待在窝里，不再强行生成到墙边。
- 小外从“世界绘制完成后叠上去”改为在原版场景排序阶段绘制，使用与家具、前景及灯光相同的遮挡流程。

请在农舍、小屋或其他室内将窝放在靠近下墙的位置，观察左右走动、坐下及睡觉是否还会覆盖墙壁。20:50 留在室内等到 21:00，观察回窝；堵路后再清出通道，检查是否能恢复回窝。夜间出门再回来、次日醒来，也请各复验一次。

## 随身灯光

- 小外带一盏原版圆形灯光，跟随位置移动，回窝睡觉时成为窝旁的小夜灯。
- 小外本身参与原版环境光照，不再绕过夜间光照保持全亮；周围照亮效果由实际 LightSource 提供。
- 收起/移动小窝、切换房间或退出存档时清理旧灯光，不向存档写入灯光或小外角色。

请在夜晚较暗的房间观察附近地板是否被照亮，再收起小窝、换房间，确认没有残留光斑。具体亮度、半径及回窝摆位仍以你的实机反馈调整。

关闭全部游戏窗口后，运行根目录 `Launch-AnniversaryQA.cmd` 加载 0.6.2；再次运行启动客机，局域网地址 `127.0.0.1`。
