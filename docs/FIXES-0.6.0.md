# 0.6.0 手动验收

本版保留 0.5.4 已认可的小外整帧参考图。完成代码与贴图调整、编译和安装包资源检查；没有启动游戏或执行自动游玩。以下均为请用户确认的实机项目，不代表已通过。

## 开始

关闭两个游戏窗口，双击仓库根目录 `Launch-AnniversaryQA.cmd`。房主进入带小屋的 `AnniversaryQA` 测试农场后，再双击启动器；客机通过局域网地址 `127.0.0.1` 加入。双方关闭失去焦点时暂停，到齐后按 F8 召集进入节日。两边控制台应显示 Welcome 0.6.0。

## 联机活动

1. **村民同步**：两边站在同一片区域观察村民走动与停下。走动由主机决定并广播起终点、开始时间及方向；客机不再随机选路线。允许网络延迟，不应走向不同地方。
2. **婚礼调查**：随机三目标，线索改成小外观察人类习惯的谜语。两边可以交换互补线索；房主单独找对一次、客机单独找对一次，均应直接让双方推进，无需另一人确认。
3. **错误村民**：先正常交谈，再右键，应该显示原台词与“就是你！/取消”，即使对方不是本轮目标也一样。选错只提示，轮次、奖励不变，可以继续找；选取消能退出。调查外商店与活动主持人的菜单照常可用。
4. **调查提示**：顶部只显示回合与本人的线索，约 12 秒后隐藏，按 F1 重看。另一人推进时，旧轮确认框应关闭，不能把旧答案提交到新轮。
5. **史莱姆练习**：双方确认后在当前站位停下，面前或附近的空格出现各自练习目标。任意一人点击后，其目标消失，另一只保留；两人完成后恢复自由移动。站得太挤且找不到空格时会取消，并提示留出空间。
6. **史莱姆比赛**：比赛在广场进行，玩家不被传送。五轮中史莱姆连续移动，抓对后只换爱心目标，不重置位置；Esc 取消后可正常行走。
7. **切蛋糕**：先让房主落刀，客机应看到固定小红条表示上一刀；蓝色游标仍在运动。交换顺序再试。邀请、取消和首次奖励规则保留。

## 场景与家中小外

1. 等待草莓成熟，确认其在框里比上一版上移 3 个原生像素（游戏 4 倍显示时约 12 像素）；采摘后消失，下次成熟重新出现。
2. 室内摆小窝，观察数分钟：每段约 8 秒，60% 概率坐下/睡觉、30% 行走、10% 待机。比例是长期随机分布，短时可能连续休息或行走。
3. 靠近右键休息中的小外，短暂挥手后下一段应行走；在它走动时右键，下一段也应行走。四周被家具堵住时先清出路径。动作继续使用已确认的整帧参考图。
