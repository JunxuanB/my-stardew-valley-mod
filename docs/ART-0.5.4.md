# 0.5.4 小外参考图美术修正

按用户最后提供的精灵图复刻外观。该附件与已保存的 `docs/references/xiaowai-user-sprites.jpg` SHA256 一致。

- 删除上版“保留上身、重画腿”的拼接处理，消除腰腿之间的水平分割线。
- 左右方向分别提取原图对应的四个完整姿势，头、身体、手臂、背包和腿来自同一帧。
- 保留原图颜色、五官和黑镜框，不再用精简绿调色板替换黑色或改画眼睛；按最后的完整参考图保留眼睛细节。
- 去除 JPEG 中烘焙的棋盘格，保留真正透明背景，以头部中心和共同脚底线对齐动作，降低步幅变化造成的整个人横向抖动。
- 使用 96×128 的详细行走帧、160×160 的居家姿态帧，在游戏中按 1 倍绘制；世界里的尺寸与旧版分别按 4 倍绘制的 24×32、40×40 帧相同。
- 原版事件角色保留原尺寸代理，用于原生帧索引、站位和碰撞；仅小外的节日绘制改用详细素材。家中角色、合影和肖像一起更新。
- 动作播放沿原帧前进再返回，依据实际移动距离切帧；没有重新发明腿部动作。其余玩法保持当前版本规则。

开发侧检查：PNG 真透明、帧尺寸/边界、原图对照与动图预览、Release 构建及安装包校验。未启动游戏做自动 QA。

请实机复验：家中左右走动的腰腿衔接和镜框厚度；节日小外、肖像及合影是否使用同一外观；角色显示大小和交互位置是否保持。预览文件位于 `artifacts/xiaowai-reference-comparison-0.5.4.png`、`artifacts/xiaowai-right-reference-0.5.4.gif`、`artifacts/xiaowai-left-reference-0.5.4.gif`，不是实机截图。
