# 0.5.0 功能测试版交付记录

## 交付内容

- 修正蛋糕绘制层级，清除草莓展示框内的运行时树木/灌木，删除商店路灯及光源。
- 接入次日预约、日历和节日冲突检查；保留固定春 2 日与 QA 全员入场入口。
- 接入主机活动状态、邀请/拒绝/取消、七种积分玩法、合影、全员闭幕确认、放灯和个人趣味记录。
- 两家商店复用原版 ShopMenu；主机检查个人限购、余额和整批背包容量后发货。
- 接入装备帽子、小窝居家角色、两种医疗卡及来信、巨大作物选择/预览/搬运。
- 奖励保存前转存模组数据并移出原版物品集合，保存完成/异常释放时恢复；加载由主机重建。
- 保留欢迎提示、启动自动更新和人工 QA 菜单。未发布 GitHub Release。

## 开发侧验证

Release / net6.0 编译通过。使用本机游戏程序集检查了商店购买、钓获、离场和聊天命令的方法签名；昏倒结算 IL 中精确匹配一处金币 setter 与一处账单添加，替换仅作用于该结算函数。此检查读取程序集元数据，没有创建 Game 实例或载入存档。

最终构建为 0 警告、0 错误。ZIP 中 DLL/全部资源与工作区一致，SHA256 校验一致，不含游戏程序集或 XNB。交付时检测到两个 SMAPI 实例正在运行，测试目录未热替换；关闭两个实例后，QA 启动器会自动从 0.5.0 包刷新两份目录。

静态预览由同一份布局生成。安装包只包含 Welcome DLL、manifest、自有/授权资源和更新脚本，不分发游戏程序集、地图或原版贴图。

## 尚未实机验收

遵照用户要求，没有执行自动游戏 QA。下列结果不能由编译或静态预览代替：真实双开结算与取消、不同窗口失焦行为、全员闭幕、保存/加载/卸载、特殊容器恢复、实际昏倒/战败，以及多人暂停/跳过钓鱼/缩放模组兼容。完整操作清单见 [手动验收](MANUAL-QA-0.5.0.md)。
