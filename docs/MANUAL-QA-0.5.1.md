# 0.5.1 本轮复验

根据玩家实机反馈和日志修改；没有运行自动游戏 QA。以下是待玩家确认的结果，不是实机通过记录。

先关闭两个游戏窗口，再用 `Launch-AnniversaryQA.cmd` 更新并双开。两端启动日志应显示 Welcome 0.5.1。此版多人协议有变化，不能与 0.5.0 混用。

1. **多人活动**：两人进入节日后，分别由房主和客机邀请对方切蛋糕、问答、调查和史莱姆；对方应收到邀请并能接受/拒绝。房主不应误报空闲玩家被占用，客机点击不应无反馈。再复验取消、超时、断线。`anniversary_qa status` 会显示 `registered=True` 与在场名单，入场成功也记入 SMAPI 日志。
2. **钓获奖励**：只显示原版财宝箱或花束，不出现鱼。财宝箱发 10 金，花束发 1 束；图标与实际奖励一致，点击后收起原版提示框，背包不增加宝箱或花束物品。花束概率 60%，财宝箱 40%，咬钩等待缩短 15%。仍需抛竿、等待咬钩和收竿，不再使用鱼类小游戏。
3. **商店**：右上角不出现额外余额数字；限购商品买完立即消失，退出重开仍售罄，无限种子一直在。购买成功无弹字，失败仍提示。检查鼠标与手柄在售罄后能继续选购其他商品。
4. **出口**：刘易斯菜单只保留比赛与取消。两人分别走到最左侧巴士站道路出口，出现原版节日多人集合/离场确认；可取消继续玩。全员确认后直接结束，不放灯、不显示闭幕统计；积分和借竿仍清理。
5. **草莓**：框子上边完整，果实底部与框边留有空隙。未成熟和采摘后完全隐藏；下一次成熟重新出现，抢收只结算一次。
6. **滚轮**：节日场内空闲时可滚动切换快捷栏物品，遵循原版反向滚动设置；钓竿使用中和进食时不能切换。商店菜单内滚动仍翻商品，不误切背包。
7. **室内小外**：小窝只能放室内；旧的室外小窝请收起搬进屋。放置后小外应在旁边空地出现，白天走动、停留并播放动作，晚上可睡觉。移动或收起小窝应刷新或移除角色。多次进出房屋/节日、客机进入小屋、回标题重进，不应再出现 `HomeXiaowai` 的空引用异常。

已完成的开发检查：Release 编译、共用布局生成与静态预览。多人网络、原版出口、钓获显示和室内移动仍需本轮实机确认。医疗卡、搬运和保存兼容逻辑本轮未扩展。
