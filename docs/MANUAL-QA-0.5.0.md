# 0.5.0 手动验收

本文件是交给玩家操作的验收清单，不是已通过的测试报告。开发侧只完成编译、静态资源和本机 API 检查，未运行游戏自动 QA。

## 开始

关闭全部游戏窗口，双击根目录 `Launch-AnniversaryQA.cmd`。房主使用农场名以 `AnniversaryQA` 开头、至少有一间小屋的测试农场。进入农场后再双击启动器一次；客机在合作/加入局域网输入 `127.0.0.1`。两边均关闭失去焦点时暂停。F8 可全员入场、借竿、增加 10 束测试积分、取消活动和发起闭幕。

每次收到新包后必须退出所有实例再启动，旧窗口不会热更新。不要用正式存档做日期、昏倒、战败和卸载测试。

## 本轮视觉修正

- 艾米丽摊位前路灯及其光源已从节日副本删除。

## 单人

1. 皮埃尔柜台应使用原版商店 UI。种子 80 金不限购，吊坠 4000 金限 1，咖啡 240 金限 5，冰淇淋 200 金限 5。关闭再开后限购不重置，取消不扣钱。满背包购买不扣钱、不部分发货。
2. 威利借竿后使用原版工具栏选竿，正常抛竿、咬钩、小游戏、收竿。成功应得到 10 金或 1 束手捧花，不增加普通鱼/垃圾。钓鱼次数进入闭幕记录。
3. 草莓首次和每次采摘后等待 75–130 秒现实时间，成熟时通知，右键先到者得 2 束。双人正式活动期间不成熟、不抢收。
4. 蛋糕可无限吃：应抛起、跳起、碎屑、揉肚子，动画完成后按原版蛋糕恢复；不扣当前背包物品、不生成可带走蛋糕。吃东西时不能开启活动。
5. 花拱右键可单人合影，短暂停留、花瓣、恢复移动；偶尔小外入镜。

## 双人（房主和客机各发起一次）

1. 选择活动→名单→对方接受，拒绝/取消/Esc/手柄 B 都可退出。名单不含自己和不在场玩家。邀请 30 秒超时。活动进行中不能同时被邀请到另一项，另一组不能抢占同项目。
2. 切蛋糕：双方各按一次空格/点击/手柄 A。差值 ≤0.15 各 2 束，否则各 1 束；每人每届首次完成领奖，重玩不重复给。Esc 取消不领奖、不锁死。
3. 地球调查：三道不重复四选一题，双方答完才揭晓；单方已答时另一方不能提前看到答案。相同答案各 1 束，三题完成后统一结算，仅首次完成领奖。
4. 线索调查：双方看到互补提示，交换线索，依次到蛋糕桌、礼物堆、花拱右键确认。需要双方到场；全部完成各 3 束，仅首次领奖。
5. 刘易斯的史莱姆：教学期间各右键抓一次自己面前的史莱姆，然后开始五轮。目标只能在比赛区内移动、不攻击；只有爱心目标计分。胜 5 束、另一人 2 束，可重玩。尽量同时点击，检查每轮只能计分一次。
6. 近距离右键另一位玩家可邀请接吻；接受后原版亲吻动作，未婚也可且不改变关系。30% 双方各 1 束，同一对共享 20 秒冷却。拒绝无动作无奖励。
7. 任一活动中让客机断开或退出，房主应收到取消提示、解除锁定、不发未完成奖励；再次连接可正常参加新活动。

## 闭幕、日期和卸载

1. 任意玩家找刘易斯或走巴士站出口发起闭幕。每个场内玩家确认；有人拒绝或 45 秒超时则继续游园。正式活动未结束时不能闭幕。
2. 全员确认后放灯约 12 秒，显示每人的趣味记录，无总冠军。回家 22:00，积分清零、借竿回收。
3. 聊天 `/yea` 或 `/welcome_yea` 预约次日；房主/客机均可。确认重复预约不叠加，春 28/冬 28 跨季跨年，遇原版/模组节日、被动节庆、婚礼冲突不覆盖；预约只举办一次。普通固定日期为春 2 日。
4. 复制测试存档，把自定义奖励分别放在玩家背包、头上、箱子、嵌套箱子、梳妆台和室内地面，过夜、退出、重新加载，检查数量/位置/旋转/主客机物品一致。
5. 再备份这份存档，卸载 Welcome 后用原版/SMAPI 载入并过夜：不应有错误物品、残留小外、幽灵家具碰撞或缺失地图。原版商品、金币和搬完的巨大作物应保留。
6. 保存失败恢复、第三方特殊容器、多人暂停、跳过钓鱼和缩放模组，需要在对应环境额外复验；无法识别的特殊容器中的奖励会恢复到原版失物招领并记录日志。
