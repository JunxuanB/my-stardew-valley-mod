# 0.5.3 调查更新与复验

## 修正

- **草莓看不到**：原版 `TemporaryAnimatedSprite.update` 会在 alpha ≤ 0 时销毁精灵。旧版隐藏后保存的引用不再属于场景，成熟时无法重现。现改为在地图世界绘制阶段根据主机 `BerryReady` 直接绘制原版草莓；未成熟不画，成熟显示，采摘后不画，每轮重新生效。
- **调查确认不明确**：移除“在目标附近任意右键就提交”的拦截。每次提交包含具体目标、点击位置和固定回合号；双方均可确认每一轮，显示自己/搭档“已确认/未确认”，不会把上一轮回调交给下一轮。重复确认只提示等待，不重复推进。
- **礼物目标**：点击 (34–36,60) 的礼物盒，才会调查礼物；小外本人不是该目标。
- **随机调查**：主机每局从 12 个候选目标中抽取 3 个不重复目标。候选为蛋糕桌、礼物堆、花拱、鱼池、新气球束、新小灯，以及海莉、艾芙琳、阿比盖尔、山姆、潘妮、玛妮。双方收到同一目标的互补线索，每轮均需两人确认。
- **村民线索**：第一次右键使用原版村民对话。正在调查时再次右键，引用该村民第一次说过的原台词，提供“就是你！”和“取消”。可猜错村民；错误目标不推进。取消仅关闭这次对话，关闭对话后按 Esc 才取消整个活动。装饰物使用“就是这里！”确认。
- **医疗卡**：月亮每人每届 20 张，火星每人每届 10 张；价格仍为 3/4 束。
- **侧面步行**：保留批准的头、身体和背包，重做髋部以下四帧交替迈腿，左向镜像；按实际移动距离推进动画，停下不继续扭动。

## 玩家复验

1. 两端退出并更新至 0.5.3。等待草莓首次成熟，确认看得见、可抢收；采摘后消失，再等下一轮，应重新出现。
2. 婚礼调查由房主发起一次、客机发起一次。每轮先让一人确认，再换另一人确认；两人都能操作，HUD 应明确显示进度。不要把“已确认，等待搭档”当成换人才能做的单人任务。
3. 抽到礼物时，点小外本人不能算完成；点她前面的礼物盒才出现物品确认。
4. 抽到村民时，先交谈一次，再次交谈应看到原台词和“就是你！/取消”。先试取消，再试选错村民，调查应继续；之后两人各找到正确村民确认。
5. 重玩几次检查目标和顺序可变化，同局不重复；熟悉气球束（东侧圆桌旁）和小灯（鱼池西侧）的摆放。原来的随机问答活动保持独立。
6. 查看两种医疗卡剩余限购，检查月亮 20/火星 10。白天回家观察小外左右行走，双腿应有交替动作；睡觉和其他居家姿态保留。

开发侧只做构建、资源/布局检查和静态图预览，没有运行自动游戏 QA。侧面动画预览位于 `artifacts/xiaowai-side-walk.gif`，地图预览位于 `artifacts/anniversary-map.png`；均不是实机截图。
