# 0.6.1 小外侧向步行

原因：参考图的左右方向四帧腿部姿势很接近，原样依序播放也几乎没有收腿动作；家中小外走完每一格、转向时又会重置步态。

修正：

- 为左右方向各增加两张经过帧，通过从髋部向下连续变形实现收腿和交替抬脚，没有裁开身体再拼接。头部、五官、镜框与上半身保持对应原帧像素。
- 左右步态按“迈开—收腿抬脚—迈开—另一脚抬起”循环，按实际移动距离推进；上下方向继续使用原来的帧序。
- 家中小外连续行走、经过格子边界与转弯时，不再重置步态；结束移动或无路可走时才回到待机。
- 穿齐小外三件套的玩家共用修正后的侧向素材和帧序。

开发侧只做素材对照、帧边界检查、编译与打包，未启动游戏进行自动 QA。

请关闭游戏，用根目录的双开启动器加载 0.6.1。在屋内摆小窝，靠近右键让小外走动，重点观察左右收腿、抬脚和连续跨格时是否仍有滑行感；再穿齐三件套左右走动。此前要求的休息比例、右键后下一段移动保持。
