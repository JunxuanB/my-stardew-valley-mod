本版只完成代码、原版数据/贴图核对、静态地图预览、编译及打包。没有启动游戏、加载存档或进行自动游玩；以下项目请用户实机验收。未发布 GitHub Release。

静态预览：`artifacts/anniversary-map.png` 与 `artifacts/anniversary-layout.png`，不是实机截图。请确认两边名单、站位一致，奶奶/莱纳斯可见可点击，格斯不会被树挡住，蛋糕桌也能单独交互。

## 莱纳斯送花

- 每次右键检查自己的手捧花余额；有至少 1 束且未达到本届个人上限时，在原版对话框里出现送花选项。可取消，不自动扣花。
- 每次赠送扣 1 束，增加 250 点莱纳斯好感（1 心），遵循原版好感数值上限；不叠加友谊书的普通送礼加成。
- 每位玩家每届最多 2 次；主机检查余额、距离与次数，重复请求不会重复扣款。房主与客机各有自己的次数与好感。
- 第一次：“我很喜欢，谢谢你。你让我觉得，我也是今天的一份子。”
- 第二次：“天哪！你简直是 good good！这两束花，我会好好珍惜的。”
- 达上限或没有余额后，普通右键不再提供送花选项。若他正是调查对象，第二次对话的“就是你！”仍然可用。

请双方分别赠送两次，核对每次减少 1 束、自己的好感增加，第三次无法继续赠送。也试一下没有花、取消赠送、调查过程中送花；送花不应误当成调查确认。正常睡觉保存后，好感应保留。

## 可重复调查与界面

- 婚礼调查目标池从 12 扩为 31，每次随机挑 3 个；新目标包含乔治、莱纳斯、贾斯、文森特、雷欧、桑迪、莉亚、玛鲁、哈维、克林特、乔迪、肯特、德米特里厄斯、艾利欧特、谢恩、潘姆、法师、科罗布斯、矮人。
- 艾芙琳仍在题库中，并与乔治使用新的鲜花对话和互相关联的线索。新增线索以人物观察、隐喻和台词含义为主，不要求查找某几个字。
- 婚礼调查可以重复完成，每次完成双方各得 3 束；小外的三题地球调查问答也能重复，每次按答案一致次数发奖。
- 婚礼调查期间顶部始终显示当前回合与自己的线索。移除 12 秒隐藏和 F1 重看，也取消搜索阶段超时。
- 一人找对即可让双方推进；猜错只提示，取消对话只关闭对话。两人都可找小外，在原版选项里选“结束这次调查”；结束后双方解除占用，没有未完成奖励，可以重新开始。
- 搜索期间 Esc/B 不再发送结束调查请求。正常离场、断线和 QA 菜单的强制取消仍会清理活动。
- 去掉“等待邀请确认”“等待两位完成选择”等通用顶部文字，以及发出邀请的额外提示。调查线索、史莱姆练习反馈和比赛比分继续显示；邀请本身仍用原版对话框接受/拒绝。

请完成并再次接取调查，核对每次都领奖；让另一人推进时看线索是否及时更新。搜索中按 Esc 不应终止调查；找小外结束、选择继续、按取消返回，分别验一次。接受蛋糕/问答邀请时顶部不应出现泛用等待条。

关闭两个游戏窗口后，运行 `Launch-AnniversaryQA.cmd` 加载 0.6.3，再启动客机通过 `127.0.0.1` 加入。F8 可给测试手捧花、召集进入节日。
