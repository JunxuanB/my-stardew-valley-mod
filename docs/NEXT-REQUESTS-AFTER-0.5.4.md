# 已实现于 0.6.0：0.5.4 小外样式交付后的新要求

用户要求先应用小外样式，再处理本清单。0.5.4 先完成参考图整帧美术；以下内容已在 0.6.0 实现，仍需用户实机验收，详见 [本轮说明](FIXES-0.6.0.md)。

- 草莓在展示框里再上移一点。
- 婚礼调查线索改成有趣、带暗示的观察，不直接让玩家找“台词里有某几个字的人”。
- 两名玩家看到的村民位置必须一致，修正当前各客户端独立游走。
- 婚礼调查任意一位玩家找对即可完成本轮；顶部只临时显示获得的线索和回合数，移除双方确认状态。
- 调查中错误村民也应在第二次点击时显示原台词与确认选项；猜错只提示，不产生其他后果，可以继续找。
- 史莱姆教学中，每名玩家点击自己的练习史莱姆后，该史莱姆立即消失，作为完成反馈。排查并去掉比赛过程中的随机传送。
- 切蛋糕：第一人落刀后，第二人的界面增加小红条标出第一人的落点。
- 家中小外大约 60% 时间睡觉或坐下、30% 移动、其余可待机；右键小外后，它下一次动作必定是移动。
- 新增可购买的小外头套、小外衣服、小外鞋子，穿齐后玩家整体呈现小外外观。
- 新增只能摆在室内的小外贴画家具。
- 修正触角头箍侧面和背面的外观，正面目前已合适。

继续遵循既定要求：原版 UI 优先、保持小镇原有布局、主机统一结算、保留欢迎提示和自动更新、用户负责实机 QA，不执行自动游玩。
