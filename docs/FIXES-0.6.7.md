# 0.6.7 老水手头像报错

原版老水手有 `Characters/Mariner` 行走贴图，但没有 `Portraits/Mariner` 头像。之前创建节日角色时虽然检查过头像是否存在，原版 `NPC.Portrait` 的延迟加载仍会在头像为空时再次调用 `ChooseAppearance`，从而打印找不到头像文件的警告。

修正：

- 创建/准备节日来宾时统一检查头像资源。头像不存在的事件角色设置原版 `portraitOverridden` 标记，阻止后续默认头像加载；标记仅作用于本次节日角色。
- 这些角色的普通对白使用无头像原版对话框，保留完整对白页。调查确认选项也使用无头像问答，不再读取该 NPC 的头像属性。
- 老水手继续在场、可以交谈；其他有头像的村民正常显示头像。若其他模组提供了有效头像资源，则仍可加载该资源。

开发侧核对了原版头像加载逻辑及本机来宾头像资源，并完成编译与安装包检查，没有启动游戏做自动 QA。

请两边更新至 0.6.7，重新进入纪念日后与老水手交谈，再在婚礼调查中重复点击他、取消确认，观察日志是否还出现 `Portraits/Mariner` 报错。也请与艾芙琳或莱纳斯交谈，确认正常头像仍显示。

关闭两个游戏窗口后，再运行根目录 `Launch-AnniversaryQA.cmd` 安装本次测试包。
