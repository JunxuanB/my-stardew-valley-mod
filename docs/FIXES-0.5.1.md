# 0.5.1 修正记录

本轮输入来自用户实机反馈，以及 SMAPI 客机日志中的 `HomeXiaowai` 换图空引用堆栈。以下记录实现和开发检查，实机结果由用户复验。

- 多人：删除远端 `currentLocation`/`Temp` 引用判定。增加按玩家 ID、日期、入场批次的登记和心跳；即使先收到了广播状态但尚未登记，也继续请求入场。名单和距离校验使用登记位置；未确认时暂存一次操作，避免客机点击无响应。取消和断线清理继续由主机处理。
- 钓获：主机提前选择下一次奖励及一次性序号，花束 60%、财宝箱 40%。原版鱼竿捞起真实的花束/财宝箱贴图，保留原版提示框至点击收起；按同一序号发 1 束或 10 金，不重新抽奖、不往背包加物品，也不产生鱼类。咬钩等待缩短约 15%。
- 商店：删除额外余额框；售罄商品移除并更新手柄导航；成功回复用于确认购买，不显示成功弹字。购买请求重试使用相同 ID，防止重复扣款。
- 离场：删除放灯、闭幕统计、刘易斯/QA 结束按钮及出口补丁。直接使用原版节日西侧出口的确认/多人集合逻辑。
- 草莓：补上展示框上沿，果实下移后根据反馈回调到离底边有空隙的位置；未成熟或采摘后 alpha=0，成熟恢复可见。
- 滚轮：节日期间补上原版被 `eventUp` 跳过的工具切换，尊重反向滚动设置；菜单和使用工具时不干扰。
- 小窝：数据由错误的“仅限室外”改成“仅限室内”；独立命名更新/绘制方法，换图位置/地图为空时清理并返回；附近空地生成，选择可走的相邻格，按屏幕保存房间状态。移动/收起家具及时更新角色。旧室外小窝需玩家搬入室内。

验证范围：C# Release 构建、当前游戏方法源码核对、地图生成与静态效果图、安装包内容/校验。没有启动游戏或存档，没有进行自动联机或玩法 QA。
