# “纪念日”节日完整实施计划

## 一、目标与确定规则

在现有 Welcome 模组中新增完整可玩的婚礼主题节日，保留欢迎提示和自动更新功能。开发针对本机已确认的 **星露谷 1.6.15、SMAPI 4.5.2、.NET 6** 环境。

- **日期**：每年春季 2 日，9:00～14:00 从镇子入场。
- **参加条件**：不限在线人数，不要求结婚；单人可以逛街、钓鱼和抢收草莓。
- **双人活动**：发起人邀请场内另一位玩家，对方确认后开始；每个项目同时只运行一组。
- **时间**：节日期间暂停，正常闭幕后回家到 22:00。
- **货币**：手捧花，采用原版恋爱花束图标；余额独立、不占背包、不能交易、离场清零。
- **限购**：除注明不限购外，均按每位玩家、每届节日独立计算。
- **中断处理**：参与者离开或掉线时取消当前双人小游戏、解除控制锁定，不发本场奖励。首版不实现断线续赛、复杂人数恢复或跨场配对。

**`/yea` 指令**

在游戏聊天框输入，将纪念日预约到次日。单人、房主和客机均可使用，由主机统一确认并保存预约。

检查次日原版节日、已注册的其他节日、被动节庆和已安排的婚礼；存在冲突则报错，不覆盖原活动。重复预约不叠加，跨季、跨年正确计算。次日再次检查冲突，预约举办一次后清除。

固定春季 2 日遇到上述冲突时跳过当届，并提示原因。

## 二、完整玩法与商品

### 场景和角色

运行时复用原版镇子婚礼的地图布局、婚礼布景和音乐，制作节日专用临时场景，不改原版婚礼剧情或玩家关系。

场地包含花拱门、花瓣通道、婚礼座椅、蛋糕长桌、两个摊位、双钓位池塘、史莱姆比赛区和巨大草莓区。通过围栏和碰撞限制游玩范围，主通道保持通畅。

村民会散步、聊天、取蛋糕；比赛时部分宾客围观加油。刘易斯负责活动入口，皮埃尔负责金币摊位，艾米丽负责手捧花打包处，格斯负责蛋糕桌。

外星人使用参考图中的黄绿色身体、黑框眼镜、圆肚子和双触角，制作像素行走与待机动画。作为临时来宾出现，不加入日常村民或好感系统。首次交互固定说：

> 不要问我来地球有什么目的。

### 游戏项目

| 项目 | 规则与奖励 |
|---|---|
| 钓鱼 | 使用真实抛竿、咬钩和收竿流程；成功钓获后，50% 得 10 金、50% 得 1 束。不产出普通鱼和垃圾。池边提供离场回收的借用鱼竿。 |
| 爱心史莱姆 | 任意玩家找刘易斯发起。教学时锁定移动，双方各练习一次右键抓取。正式比赛五轮，每轮生成 5 只无攻击性的史莱姆，其中 1 只有爱心；先抓到得 1 分。胜者得 5 束，另一人得 2 束，可重复参加。 |
| 巨大草莓 | 一株节日专用巨大草莓，首次及每次采摘后随机等待 75～130 秒现实时间成熟，向场内玩家提示。先右键采摘者得 2 束，不额外产出背包物品。 |
| 接吻 | 近距离右键另一玩家发起，对方确认后播放接吻。每次有效判定有 30% 概率双方各得 1 束；同一对玩家共享 20 秒奖励冷却。未婚可用，不改变恋爱或婚姻关系。 |
| 双人切蛋糕 | 两人在 0～1 的移动刻度上各按一次；落点差不超过 0.15，双方各得 2 束，否则各得 1 束。每人每届第一次完成领奖，之后可重玩。 |
| 默契问答 | 从内置中文题库抽取三道不重复的四选一问题，秘密选择后同时揭晓。每题答案相同，双方各得 1 束。每人每届首次完成领奖。 |
| 外星婚礼调查 | 两人领取互补线索，依次找到蛋糕桌、礼物堆、花拱门，双方均在目标处确认后推进。完成三处调查，各得 3 束；每人每届只能领奖一次。 |

史莱姆限制在比赛区内移动；抓错只给反馈，不扣分。比分和抢收结果由主机统一判定，一次目标只结算一次。

有正式双人小游戏进行时，巨大草莓暂停生长和采摘，全部结束后恢复，避免参与活动的人错过抢收。

问答题库首版包含 12 道日常偏好和外星人趣味题，不考攻略、不把不同答案评价为感情不好。

### 休闲与闭幕

- **无限蛋糕**：婚礼蛋糕桌可反复现场食用，恢复体力，不提供积分、不生成可带走的食品。
- **合影**：花拱门处支持单人、双人站位，触发花瓣和短暂定格；外星人偶尔探头入镜。
- **闭幕**：找刘易斯发起，场内玩家确认后播放放灯演出；单人也可结束。
- **趣味记录**：展示每人的钓鱼次数、史莱姆胜场、草莓采摘次数和接吻奖励次数，不设置总冠军。
- **离场**：提醒剩余手捧花将清零，清理借用物品和临时角色，再按原版回家流程将时间设为 22:00。

## 三、奖励行为与技术实现

### 帽子、家具和消耗品

- **触角帽子**：真实可装备帽子，制作四方向像素贴图，仅有双触角，不附加属性。
- **外星人家具**：真实可摆放的小窝，放置于农舍或小屋室内后生成活动外星人；在同房间可行走区域闲逛、坐下、推眼镜，不挡路。收起小窝时同步收回外星人。
- **月亮医疗卡**：放在随身背包时，户外因熬夜或精力问题昏倒且本来需要收费，自动消耗一张并免除费用；次日收到外星人送回家的来信。
- **火星医疗卡**：放在随身背包时，生命值归零进入战败救援，自动消耗一张，阻止本次费用及物品丢失；正常回到救援地点。
- **巨大作物移动工具**：一次性工具，只移动同一农场内的原版巨大作物。选中后显示原位置和新落点预览，成功放下才移动并消耗；取消或无效落点不改变作物。保留原作物种类和状态，不支持节日草莓。

医疗保护作用于对应救援结算，不能通过粗略恢复钱包或背包快照覆盖同时发生的正常交易。

### 模块和接口

在现有 C# 模组内按节日调度、场景、活动、商店、奖励、多人同步和存档兼容拆分服务，`ModEntry` 只负责启动和注册。

- 通过 SMAPI 内容接口注册节日日期、临时地图、物品数据、贴图和中文文本；无需新增 Content Patcher 等玩家依赖。
- 注册带模组前缀的聊天命令，并提供 `/yea` 别名。
- 主机维护活动实例、个人积分、限购、一次性奖励和比赛结果；客户端发送交互请求，接收状态同步。重复请求不得重复扣款或发奖。
- 新增最小内部数据类型：节日会话、个人活动记录、双人项目状态、持久奖励记录、次日预约。
- 接吻、救援费用及必要的节日交互通过局部 Harmony 补丁接入，只在相应功能生效时改变行为。
- 自定义资源采用模组命名空间；像素 PNG 随包分发，原版资源在运行时引用。

节日注册和临时地图按照游戏现有节日机制实现。[节日数据接口说明](https://wiki.stardewvalley.net/Modding:Festival_data)

### 卸载兼容作为第一项技术验收

采用“**游戏运行时是真实物品，保存时转存模组数据**”的方式：

1. 保存前收集自定义帽子、家具和消耗品的类型、数量、装备或存放位置。
2. 主机通过 SMAPI 存档数据保存记录，临时从原版物品集合移除这些实例。
3. 原版保存完成后恢复运行时实例；保存失败时也恢复内存状态。
4. 装着模组加载存档时，从记录重建奖励；不装模组时，原版存档里没有自定义物品实例或临时角色。

使用原版全世界物品遍历接口覆盖背包、装备、箱子、已放置家具及嵌套容器；持久化记录使用普通数据，不保存自定义 CLR 类型。SMAPI 支持存档专用数据存取。[数据接口说明](https://wiki.stardewvalley.net/Modding:Modder_Guide/APIs/Data)

卸载后允许留下原版忽略的模组数据记录，但不得出现错误物品、缺失地图、幽灵碰撞或加载失败。原版商品、金币和已经移动完成的原版巨大作物保留。

待投递医疗信件随模组记录保存，加载模组时生成，避免卸载后出现缺失正文的信件。

## 四、实施顺序与交付

1. **存档兼容基础**：完成一件测试帽子和家具的保存、重载、卸载验证，以及主客机物品恢复；通过后再扩展完整奖励。
2. **节日主流程**：完成日期、日历、`/yea`、婚礼场景、来宾、时间暂停、两个摊位和 22:00 回家。
3. **完整活动与奖励**：实现全部七种赚币玩法、蛋糕、合影、闭幕、家具动画、医疗卡和巨大作物搬运。
4. **联机和视觉打磨**：检查操作距离、碰撞、对话、动画、字体缩放、多人结果与奖励节奏。
5. **打包交付**：版本升级为 0.4.0，更新描述和 README；扩展构建脚本打包贴图、地图配置和翻译文件，补充资源完整性检查，生成可安装 ZIP。

保留自动更新的启动阻断保证，并调整现有启动测试，避免其依赖“恰好注册三个事件”的旧实现。交付包括源码、安装包、测试记录和游戏截图；本次不包含发布 GitHub 正式 Release。

## 五、测试与验收

**自动化测试**

- 春季 2 日、`/yea`、跨季跨年、重复预约及活动冲突。
- 钓鱼和接吻的两种概率分支、奖励冷却、一次性领奖。
- 五轮比赛计分、主客机发起、同时抓取或采摘只结算一次。
- 个人限购、草莓种子不限购、两种货币、余额不足和背包已满。
- 医疗卡正确区分昏倒与战败，每次只消耗对应一张。
- 巨大作物合法移动、取消、碰撞位置拒绝。
- 自定义物品保存恢复、卸载后存档无自定义实例、普通物品不受损。
- 原有包验证、更新器和启动阻断测试继续通过。

**可见的实机测试**

使用专用测试农场和独立测试模组目录，先备份相关测试数据；当前游戏中的正式存档不用于推进日期或测试死亡。

通过 Windows 屏幕操作进行入场、走动、对话、购买、小游戏、接吻、搬运与离场。开发辅助命令仅用于测试存档准备日期、资金和材料，正式交互仍通过游戏画面完成。

依次验证：

1. 单人完整游园，确认没有人数门槛。
2. 本机双实例经局域网连接，分别操作房主和客机，确认客机能发起活动、兑换并获得奖励。
3. 一次完整闭幕和次日保存重载。
4. 实际昏倒、战败及外星人来信。
5. 帽子装备、家具放置和箱中存放后，退出并卸载本模组，再用原版加载测试存档并正常过夜。
6. 与本机已有的多人暂停、跳过钓鱼小游戏和缩放模组进行兼容检查。

交付时区分自动测试与实际游戏验证，附关键场景截图及日志结果。双实例联机、卸载重载和完整节日闭幕都是验收项，不能以编译成功代替。
